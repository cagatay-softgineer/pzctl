        Profiles
        
            
          
        
          
        Each profile is a separate world with its own settings.
            Switching changes which one the server loads — nothing on disk is moved.
        
          
          
          
          
            
            
            
          
          
        
          
        
          
          
          
            
          Server update
          
            
            
          
          
          
          
            
          
          
          
          Updates the game server itself. The server must be stopped, a backup is
            taken first, and progress appears in the Dashboard console. Leaves your world,
            config and mods alone.
          
        
          
        
          
          
          
            
          Remote access
          
            
          
          
          
          
            
            
          
          
          
          
            
            
            
          
          
          
          Publishes this panel on the internet over HTTPS. The access token
            becomes the only thing protecting your server — anyone who has it can
            control it. With a token set you get a stable hostname; without one, a temporary
            address that changes each time.
          
        
          
        
          
          
          
            
          Notifications
          
            
          
          
          
          
            
            
            
            
            
            
          
          
          
          pzctl’s own notifications, separate from the game’s Discord
            bridge in the server INI. Sent only when one of these happens.
          
        
          
        
          
          
          
            
          Performance
          
            
          
          
          
          
          
          
          Diagnoses memory creep. Adds JVM logging flags; off by default.
          
          
          
          
        
          
        
          
          
          Logging
          
          
          
            
            
          
          
          
          Applied at launch, so they need a server restart. Category names are
            the game's DebugType values — pzctl passes them through rather than guessing a list.
            Common ones: All, General, Network, Sound, Lua, Mod.
